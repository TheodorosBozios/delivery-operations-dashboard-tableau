## Dashboard Overview

This dashboard helps monitor and analyze delivery operations with a clear operational view of:

- Total orders
- Average delivery time
- Orders by city
- Average delivery time by city
- Orders by day and city
- Correlation analysis

## Worksheets Included

| Worksheet | Description |
|-----------|-------------|
| **Total Orders** | High-level order volume overview |
| **Avg Delivery** | Average delivery time KPI |
| **Orders by City** | Geographic distribution of orders |
| **Avg Delivery Time by City** | Performance comparison across cities |
| **Orders by Day and City** | Time + location breakdown |
| **Correlation Analysis** | Relationship analysis between key metrics |
